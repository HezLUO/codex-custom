# 默认通过终端命令安装预编译版本

为让有同类需求的用户方便安装，默认提供一条终端命令，下载并安装经过验证的预编译版本；源码与补丁继续公开，本地构建保留为开发者的可选方式。相较于让每位用户安装工具链并编译大型 Rust 工作区，项目承担成品构建、验证与版本维护工作。安装方式的调查见[调查记录](../INSTALLATION-RESEARCH.md)。

首版限定已验证的 macOS Apple Silicon 和明确匹配的官方 CLI 版本。官方升级后若暂无匹配成品，明确提示兼容范围和官方程序恢复入口，不自动让用户进入本地编译。普通用户的默认安装与启动不依赖 Rust 构建工具链。

发布产物需单独整理和审查，不直接上传维护者的现有安装目录，也不包含私人配置、凭据、会话或日志。仅移动和整理源码目录无需重复既有完整构建；发行包仍需相应验证。本决定记录目标，预编译下载、安装和更新流程尚未实现。
