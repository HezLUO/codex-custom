## 真实隔离安装与功能

本次以实际已清理的前端，在 macOS Apple Silicon、官方 standalone 0.164.0、layout v1 下验收。测试 HOME、CODEX_HOME、state、命令入口与会话数据均位于隔离目录，不提供 Rust/Cargo/Git 或源码构建能力。安装与离线命令另以禁止读取源码 checkout 的方式验证独立性；原生进程发现需要 ps，前端首次启动临时后台服务的专项检查直接运行已安装入口，与强制源码读取拒绝的检查分别记录。测试没有登录资料或模型推理请求。

- 本地实际候选安装后入口不依赖 checkout；严格签名、`--version`、帮助及 resume 参数路径通过。官方包除主前端替换外，helper、rg、voice 和元数据逐文件一致；官方入口和选择链接不被替换。
- 从终端 shell 引导器，通过本机 HTTP 测试服务依次取得 Python 引导器、精确版本描述和实际归档，安装成功。随后停掉服务，已安装入口仍可运行 `--version` 和 `resume --help`。此项不是公开 GitHub 下载成功的证据。
- 使用合成的分页恢复会话，实际 PTY 中默认底栏与 `/status` 均为 `95% left (33.8K used / 475K)`。当前用量 33,800 与合成累计用量 99,999 不同；底栏未误用累计值。服务为 Local background server，恢复及退出成功。分别核对默认偏好与显式前端字段偏好；未自动添加改变服务选择的参数。
- 使用当前收据格式的两份实际候选，完成同官方版本 `0.164.0-custom.4` 到 `0.164.0-custom.5` 的测试服务下载更新；新 current 生效、旧发行保留。停掉服务后版本与 resume 帮助、严格签名仍通过，更新前后官方包及临时用户文件一致。
- 由真实前端启动尚未运行的隔离官方后台服务，实际 PTY 中上下文、状态、服务、恢复与退出均通过。前端仍活动时清理拒绝；前端退出后默认卸载、重复卸载、重装与可选清理通过，后台服务的同一 PID 与进程身份全程仍在运行，且不再持有前端运行租约。仅在此项证明完成后才清理测试服务与其残留 socket，未操作日常服务。
