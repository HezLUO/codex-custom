## 此前同功能补丁的验收（历史结果）

此前在 macOS Apple Silicon、官方 CLI 0.164.0 进行过完整本地 release 构建、strip/ad-hoc 签名、包资源核对和交互恢复验收。五组针对性 TUI 测试通过，共 75 项；底栏和 `/status` 当前上下文数值一致，Server 显示 Local background server，未强制 embedded 模式。

当时全量 TUI 库结果为 5,788 通过、38 失败、4 忽略。37 项与发布版本号引发的官方快照差异相关；剩余 1 项源于上游两个测试重复调用同一 inline snapshot 断言的保护机制，已在官方无补丁源码对照复现。诊断期间的临时测试修正没有进入运行补丁。全量套件不能称为全绿；原始诊断材料因包含机器上下文而未迁入公共候选。

历史验收没有逐项覆盖所有命令、远程服务器、语音和模型请求，也没有运行整个多 crate 工作区的全部集成测试。不能保证任意环境和未来版本绝对等价。
