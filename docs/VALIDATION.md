## 首次原生 CI 构建与修正

Linux x64 首次原生构建完成相关 Rust 测试过滤器与 CLI release 编译，但在二进制隐私准入处失败，因此没有形成已验证安装包。固定版本的四个平台官方参考二进制用于复现：预编译 native/V8 组件仍保留 CI 构建路径，普通编译器路径映射不足以移除；紧密排列的公开检测器前缀和 CLI 帮助文字产生凭据模式误判，Windows 固定网络标识产生会话标识误判。
